# Legacy code

`lifeos-streamlit/` is an earlier, unrelated Streamlit prototype ("LifeOS") that lived at the
repository root before The Blue Legacy Foundation website was scaffolded. It is preserved
unchanged for reference and is not part of the website build, tests or deployment.

Note: `lifeos-streamlit/.streamlit/secrets.toml` contains only a placeholder key. Never commit
real secrets to this repository.
